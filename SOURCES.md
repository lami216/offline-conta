# Sources and Attribution

## Everything Claude Code (ECC)
- Repository: https://github.com/affaan-m/ECC
- License: MIT
- Author/copyright notice preserved in `LICENSES/ECC-MIT.txt`.

ECC concepts and representative structures that informed this kit include:
- project skills (`SKILL.md` with descriptive metadata);
- Codex project guidance and read-only specialist roles;
- security review, API design, coding standards, accessibility, frontend design direction, planning, verification, and related engineering workflows.

This kit does not attempt to mirror the entire ECC repository. Much of the content here is rewritten, consolidated, or newly authored for a reusable Codex project template, especially the e-commerce, accounting/financial, Arabic/RTL, platform, and cross-stack rules.

## OpenAI Codex
The kit uses project-local conventions intended for Codex, including repository `AGENTS.md`, project skills, and project-local `.codex` configuration.
Current Codex documentation should be treated as authoritative if a future Codex release changes discovery/configuration behavior.
